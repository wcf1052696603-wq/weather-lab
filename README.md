# 全年天气对比 · Weather Lab

一个可以对比**任意城市全年气候**的本地程序：温度、湿度、降水、光照、极端天气，
并基于数据给出**宜居参考分**与**居住建议**。支持中国主要城市与全球主要城市，
也可以搜索加入世界上任何一个城市。

---

## 一、怎么用

### 方式 A：直接双击打开（最简单）

双击 `index.html` 即可。内置 112 个城市的数据已经打包在 `data/climate-data.js` 里，
所有图表与建议都是本地计算，**断网也能用**，只有「搜索新城市」需要联网。

> 若浏览器因安全策略不允许本地文件加载脚本，用方式 B。

### 方式 B：本地起一个小服务（推荐）

```bash
cd weather-lab
python -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777/
```

## 二、数据来源与口径

- **预设数据集**：**NASA POWER Daily API**（MERRA-2 再分析，`community=AG`），
  源分辨率 0.5°×0.625°（约 50 km），NASA 官方做过偏差订正。
  免密钥、全球覆盖、明确支持程序化访问。
- **在线搜索的城市**：浏览器直接调用 **Open-Meteo**（ECMWF ERA5 再分析，约 25 km）实时抓取。
  两者同为再分析资料，量级一致，但存在小幅系统性差异（降水尤其明显）。

> 为什么预设数据用 POWER 而不用 Open-Meteo？Open-Meteo 的历史接口对批量下载有严格的
> **按小时请求数**限制（`Hourly API request limit exceeded`），一次抓 100+ 城市会被限流；
> POWER 则明确面向程序化访问设计。程序里保留了 `scripts/fetch_climate.py`（Open-Meteo 版，
> 带断点续传与指数退避），供少量城市时使用。

- **统计期**：`2015-01-01 ~ 2024-12-31`（10 个完整年份）。
- **月度值**：先计算每年该月的日均值，再对 10 年取平均，避免各月天数不同造成的偏差。
- **年度值**：降水、雨日、暴雨日、高温日、霜冻日等为 12 个月之和，即年平均的年总量。
- **派生指标**：
  - 体感温度 = Steadman 表观温度 `T + 0.33e − 0.70v − 4.00`（e 为水汽压 hPa，v 为风速 m/s）
  - 采暖度日 `HDD = Σ(18 − 月均温) × 月天数`，制冷度日 `CDD = Σ(月均温 − 24) × 月天数`
  - 雨日 ≥1 mm；暴雨日 ≥25 mm；特大暴雨日 ≥50 mm
- **光照**：用**入射太阳辐射**（MJ/m²·日，POWER 的 `ALLSKY_SFC_SW_DWN`），
  比日照时数更稳定可比，不依赖各国日照阈值定义。
- **风速**：`WS2M`，2 m 平均风速，非日最大风速。

### 宜居参考分怎么来的

六项分维度（各 0~100 分）加权：

| 维度 | 主要依据 | 扣分项 |
|---|---|---|
| 冬季宜居度 | 最冷月均温（6~20℃ 满分） | 霜冻天数 |
| 夏季宜居度 | 最热月均温（19~27℃ 满分） | ≥35℃ 天数、夏季湿度、≥30℃ 天数 |
| 干湿适宜度 | 年均湿度（45~70% 满分） | 高湿月份数、过干 |
| 光照条件 | 年均太阳辐射（13~20 MJ 满分） | 最弱月份辐射过低 |
| 降水适宜度 | 年降水（550~1350mm 满分） | 降水集中度、暴雨日 |
| 气候温和度 | 综合扣分制 | 年温差、极端最高/最低、雨日过多 |

权重可由界面上的四个滑块按个人偏好调节（怕冷 / 怕热 / 怕潮 / 重视日照）。

> **免责声明**：评分与建议全部由公开气候数据推导，用于横向比较参考，
> 不构成购房、投资或医疗建议。再分析数据代表所在网格的平均状态，
> 与市区自动站实测可能有 1℃ 量级的差异，山地城市偏差更大。

## 三、目录结构

```
weather-lab/
├── index.html                  程序主页面
├── app.js                      逻辑：图表、评分、建议引擎、在线抓取
├── styles.css                  样式
├── vendor/chart.umd.min.js     本地图表库（离线可用）
├── data/
│   ├── cities.json             城市库（112 城，含经纬度）
│   ├── climate.json            气候数据（抓取产物）
│   ├── climate-data.js         同上，打包为浏览器可直接引入的 JS
│   └── _review.txt             地理编码校验记录
├── scripts/
│   ├── build_cities.py         构建城市库（地理编码 + 人工校正）
│   ├── patch_cities.py         修正歧义匹配、规范港澳台归属
│   ├── fetch_power.py          【主】NASA POWER 抓取 10 年逐日数据 → climate.json
│   ├── fetch_climate.py        【备】Open-Meteo 版抓取（带断点续传与指数退避）
│   ├── emit_js.py              climate.json → climate-data.js
│   ├── climate_core.py         Python 版评分/建议引擎（与 app.js 同口径）
│   ├── make_report.py          生成两城对比报告（自包含 HTML）
│   └── test_app.mjs            Node 冒烟测试（DOM 桩，跑通全部渲染路径）
└── 全年气候对比_惠州_vs_芜湖.html   示例报告
```

## 四、常用命令

```bash
# 重新抓取气候数据（NASA POWER，可随时中断，下次自动续传）
python scripts/fetch_power.py
python scripts/emit_js.py                 # 打包给浏览器

# 重新生成城市库（需要联网）
python scripts/build_cities.py
python scripts/patch_cities.py

# 生成任意两城的对比报告
python scripts/make_report.py 惠州 芜湖

# 冒烟测试
node scripts/test_app.mjs
```

> 抓取脚本对 Open-Meteo 的**按小时请求数**限制做了适配：单次请求携带 24 个城市、
> 批次间限速、失败指数退避，并在每批后落盘（`data/climate.partial.json`）以便续传。
